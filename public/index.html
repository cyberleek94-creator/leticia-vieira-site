Como faço para acessar o pacote?

Como funciona o pagamento?

O pagamento é feito via Pix. O site apresenta um QR Code e um código Pix copia e cola, quando a cobrança é gerada corretamente.

O pagamento é recorrente?

Os planos apresentados são de pagamento único. Confira sempre o valor e os detalhes mostrados no checkout antes de pagar.

Quem é Letícia Vieira?

Letícia Vieira é uma personagem virtual criada com inteligência artificial. As imagens e a apresentação deste site fazem parte desse projeto virtual.

O que faço se meu Pix não aparecer?

Verifique o aplicativo do seu banco e aguarde a confirmação. Não faça um segundo pagamento sem antes verificar o estado da primeira cobrança.
